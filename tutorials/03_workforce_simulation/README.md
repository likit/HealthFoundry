# Tutorial 3: Simulate Workforce Changes

This tutorial runs a five-year workforce simulation with transfers, resignations, and retirement eligibility.

## Run it

From the repository root:

```bash
python tutorials/03_workforce_simulation/simulate_workforce.py
```

Or with the project virtual environment:

```bash
.venv/bin/python tutorials/03_workforce_simulation/simulate_workforce.py
```

## What it demonstrates

- Configuring a multi-year simulation
- Setting workforce transition rates
- Applying a retirement-age rule
- Recording workforce events
- Inspecting closed and active employment episodes
