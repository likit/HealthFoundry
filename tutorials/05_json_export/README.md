# Tutorial 5: Export a World to JSON

This tutorial builds a small world and writes its canonical representation to `tutorial_output/world.json`.

## Run it

From the repository root:

```bash
.venv/bin/python tutorials/05_json_export/export_json.py
```

## What it demonstrates

- Calling `world.to_json()`
- Writing the canonical nested representation to a file
- Reading the JSON back for inspection
